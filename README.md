# Flipkart-Customer-Support-Analysis
Flipkart Customer Support Analysis and CSAT Score Prediction

Project Overview

This project focuses on analyzing Flipkart's customer support dataset and predicting Customer Satisfaction (CSAT) scores using Machine Learning techniques. The project aims to identify the factors influencing customer satisfaction and provide insights that can help improve customer support services and enhance customer experience.

Project Type

- Exploratory Data Analysis (EDA)
- Classification (Machine Learning)

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

Machine Learning Models Used

1. Random Forest Classifier
2. Decision Tree Classifier
3. Logistic Regression

Evaluation Metrics

- Accuracy Score
- Classification Report
- Confusion Matrix
- Feature Importance

Repository Contents

- Flipkart_EDA.ipynb
- Flipkart_ML.ipynb
- customer_support_data.csv
- Project PPT
- README.md

Business Objective

The objective of this project is to analyze customer support interactions and predict customer satisfaction levels. The insights obtained can help improve customer experience, optimize support operations, and enhance customer loyalty.

Conclusion

Among the three models developed, the Random Forest Classifier was selected as the final model due to its superior performance and robustness. The project demonstrates the usefulness of machine learning in solving real-world business problems and improving customer support services.
